# Django图书管理系统测试指导

## 1. 测试对象

**测试对象**：基于Django的在线图书管理系统

**功能模块**：
- 用户管理模块
- 图书管理模块
- 借阅管理模块
- 统计分析模块

## 2. 测试环境要求

### 2.1 硬件要求
- CPU: 2核及以上
- 内存: 4GB及以上
- 存储空间: 10GB及以上
- 网络: 本地网络连接

### 2.2 软件要求
- **操作系统**：Windows 10/11、Linux、macOS
- **Python**：3.9+
- **Django**：4.2+
- **数据库**：SQLite（默认）
- **浏览器**：Chrome 90+、Firefox 88+、Edge 90+
- **依赖包**：详见requirements.txt

### 2.3 环境准备
1. 克隆项目代码
2. 创建虚拟环境并激活
3. 安装依赖包：`pip install -r requirements.txt`
4. 运行数据库迁移：`python manage.py migrate`
5. 创建测试数据
6. 启动开发服务器：`python manage.py runserver`

## 3. 测试工具选择

| 测试类型 | 工具 | 用途 |
|---------|------|------|
| 功能测试 | 手动测试 + Django测试框架 | 验证功能正确性 |
| 性能测试 | Django测试框架 | 基本性能验证 |

## 5. 详细测试步骤

### 5.1 用户管理模块测试

**1. 注册功能测试**
- **测试步骤**：
  1. 访问 `/users/register/`
  2. 填写注册表单（用户名、姓名、邮箱、密码）
  3. 点击"注册"按钮
- **预期结果**：
  - 注册成功并跳转到登录页面
  - 显示"注册成功！请登录。"的提示
- **成功标准**：
  - 新用户账号创建成功
  - 可以使用新账号登录

**2. 登录功能测试**
- **测试步骤**：
  1. 访问 `/users/login/`
  2. 输入用户名和密码
  3. 点击"登录"按钮
- **预期结果**：
  - 登录成功并跳转到首页
  - 显示"欢迎回来，[用户名]！"的提示
- **成功标准**：
  - 成功登录系统
  - 导航栏显示用户信息

**3. 个人资料管理测试**
- **测试步骤**：
  1. 登录系统
  2. 点击导航栏中的"个人资料"
  3. 修改个人信息（如手机号、地址）
  4. 点击"保存修改"按钮
- **预期结果**：
  - 个人信息更新成功
  - 显示"个人资料更新成功！"的提示
- **成功标准**：
  - 个人信息在数据库中更新
  - 页面显示更新后的信息

**4. 权限控制测试**
- **测试步骤**：
  1. 使用普通用户登录
  2. 尝试访问管理员页面（如 `/books/books/create/`）
- **预期结果**：
  - 被重定向到登录页面或显示权限不足提示
- **成功标准**：
  - 普通用户无法访问管理员功能
  - 管理员可以正常访问所有功能

1. **完整性**：覆盖所有功能模块的测试
2. **准确性**：测试步骤和结果描述准确
3. **可追溯性**：每个测试用例都有明确的预期结果和实际结果

## 8. 测试注意事项

1. **测试环境隔离**：使用独立的测试环境，避免影响生产数据
2. **测试数据清理**：测试完成后清理测试数据
3. **边界情况测试**：测试各种边界情况，如空输入、异常输入等
4. **权限测试**：严格测试权限控制，确保不同角色只能访问相应功能
5. **兼容性测试**：在不同浏览器中测试系统
6. **性能测试**：在正常和高负载情况下测试系统性能
